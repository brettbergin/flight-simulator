# Whole-flight engineering preview

Windows x64, PowerShell 7+, original synthetic flight model with tricycle gear. The player includes an original high-wing aircraft, procedural cockpit interior with a live physical dashboard, synthetic airfield scenery, responsive graphical instruments, camera controls, a local airfield map, smooth pilot input and procedural sound. This is not a C172, validated landing lesson or qualified training device. Instruments display derived native truth, with TAS and ellipsoid height explicitly labeled.

Build the pinned native toolchain first, then:

```powershell
$proof=(Get-Content .local/export-proof/latest-run.json -Raw | ConvertFrom-Json).root
./tools/interactive-preview/run.ps1 -ExportProofRoot $proof -ToolchainRoot .local/toolchain
$run=Get-Content .local/interactive-preview/latest-run.json -Raw | ConvertFrom-Json
& (Join-Path $run.payload 'launch.ps1')
```

## Selectable original cold piston profile

This opt-in profile is an original engineering model with an idealized starter supply. It does not implement a manufacturer checklist, C172S performance, a battery/electrical system or licensed flight-training credit. The default ready-to-fly profile remains available. The coupled-source build must pass its own native, editor, portable and rebuilt-DLL checks before its package is accepted.

Pause and choose **Aircraft: ready-to-fly prototype · switch** to request the cold piston prototype; confirm a fresh attempt when prompted. This starts on the ground in calm conditions with brakes held, 100 kg fuel, mixture at zero, ignition off, starter released and fuel feed on. Native tick0 has a stopped shaft and no combustion; selecting or resetting the profile performs no hidden warm-up. Airborne starts and non-calm wind are unavailable in this profile.

With the default piston keyboard preset, resume and keep brakes held. Hold **period** to increase mixture toward rich; **comma** decreases it. **F8/F9** independently toggle left/right ignition, **F10** toggles fuel feed, and holding **F12** commands the starter. Check native MIX/IGN/FEED/START indications before cranking. Release F12 after combustion begins. These are simulator controls for this original prototype, not a real-aircraft starting procedure. Throttle and brakes retain their ordinary bindings, including **X** idle, **B** brake hold and **Space** momentary brakes.

The engine strip reports copied native shaft RPM, combustion state, throttle, mixture, fuel, ignition, starter, feed and starvation. An unavailable reading shows unavailable; a paused or historical publication remains labeled. Starter-on and engine-running are separate facts. The propeller can coast while combustion is off. Mixture cutoff, ignition off or feed cutoff acts through native simulation; no UI action directly edits aircraft velocity or RPM.

**F7 Controls** edits the selected profile's bindings and calibration while paused. Version1 presets remain ready-to-fly presets. Their piston migration is an explicit draft requiring review and Apply; switching profiles does not silently convert or overwrite a saved preset. The two profiles retain separate in-memory presets. Release the starter before resuming: pause/focus loss clears local starter intent, and native starter-release admission must succeed before flight advances.

Cold-profile observation recording and new-review Save are currently unavailable and say so. Previously saved ready-to-fly reviews may still be opened as historical observations. The optional map and route board remain geometric aids; wind-derived cues stay unavailable where their legacy profile contract does not apply.
