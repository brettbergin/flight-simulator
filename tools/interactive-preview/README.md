# Whole-flight engineering preview

Windows x64, PowerShell 7+, original synthetic flight model with tricycle gear. The player includes an original high-wing aircraft, procedural cockpit interior with a live physical dashboard, synthetic airfield scenery, responsive graphical instruments, camera controls, a local airfield map, smooth pilot input and procedural sound. This is not a C172, validated landing lesson or qualified training device. Instruments display derived native truth, with TAS and ellipsoid height explicitly labeled.

Build the pinned native toolchain first, then:

```powershell
$proof=(Get-Content .local/export-proof/latest-run.json -Raw | ConvertFrom-Json).root
./tools/interactive-preview/run.ps1 -ExportProofRoot $proof -ToolchainRoot .local/toolchain
$run=Get-Content .local/interactive-preview/latest-run.json -Raw | ConvertFrom-Json
& (Join-Path $run.payload 'launch.ps1')
```

No accounts or runtime Python/Node/compiler required. Launcher requires PowerShell 7 and puts userdata beside the fresh payload, with an empty PATH and app-local native libraries. `-HeadlessSmoke` runs an explicitly automated pilot-API driver, plus pause/reset/control/close assertions. The package gate compares exact editor/exported records (except fresh session IDs), verifies all seven actually loaded native module paths/hashes and the full PE/CRT closure, pins the new model, and reruns the combined loop with a separately rebuilt JSBSim DLL in a Unicode path. `-VisualSmoke` is a separately scheduled GPU diagnostic with thirty-nine viewport captures, including both runway ends, low approach, intersections, fields, coverage boundary/corner a camera-only sweep/return, six named landmark observers, reciprocal runway selection, compact locator and fault views while the native aircraft stays paused and unchanged. `-Airborne` starts the human mode airborne; default is ground-ready with brakes held. A watchdog limits smoke processes.

Choose Resume, runway or airborne start from the initial menu. Arrow keys roll/pitch (Down raises nose), A/D yaw and nose-wheel steering, PageUp/PageDown or W/S throttle, [/] trim. B toggles brake hold; Space momentary both brakes; Q/E individual brakes. Pilot axes ramp at 0.9 normalized units/second toward the selected sensitivity; this input mapping has no attitude/velocity feedback. P or Escape opens/resumes the pause menu; quitting is a deliberate menu action that joins the worker and retires audio. G starts a fresh ground session; F fresh airborne; R restarts the current start.

1/2/3/4 select cockpit/chase/orbit/focused panel; C cycles views. Hold right mouse to look, scroll to zoom, Home to recenter. H shows controls/provenance; V toggles an additional instrument overlay; M mutes audio; F11 toggles fullscreen. The cockpit has an original procedural interior and a live dashboard texture driven by the same copied state as the overlay. Its yoke, pedals, throttle and trim animate held pilot commands; they are presentation, not clickable systems or manufacturer geometry. The cockpit defaults to the physical panel, with flight faults still visible in the top status bar. The minimum supported window is 960×540. Original farms, water, woodland, roads, bridge, village and hangar details provide visual references. Water is cosmetic and retains flat-plane contact behavior. Decorative scenery has no colliders; the immutable prepared plane remains the only ground surface. Grass, pavement and paint now share one opaque shader-painted plane, avoiding competing millimetre-separated surfaces. Distance filtering smooths thin paint/grass detail and four-sample MSAA smooths geometry edges. A decorative ground skirt fills the gap beneath the distant hills; native coverage is unchanged. See [environment stability evidence](../../docs/evidence/P1/environment-stability.md).

Tab shows the north-up airfield locator; +/− changes horizontal span between 1 and 32 km. It uses the accepted scenery tangent frame (east/right, north/up) and synthetic runway/apron/taxiway bounds. Aircraft position and projected nose direction come from copied native pose; a near-vertical nose has no heading arrow. T selects runway 36 or 18 while the map is visible. Six named original rural landmarks match their scenery positions. Planar range, true bearing, before/past physical runway end and left/right of the selected inbound axis help locate the field; an offscreen pointer targets that selected end. These are synthetic geometric pavement ends, not sourced operational thresholds. The height is copied native reference-plane CG clearance, explicitly not MSL or wheel clearance. Fault/retained/empty states suppress numeric guidance and the aircraft/trail; paused state is labeled. See [rural scenery/locator evidence](../../docs/evidence/P1/airfield-landmarks.md). The local, in-memory trail samples at most once per native second, keeps up to 600 points, and clears on a fresh native session. This is not a chart, GPS sensor, recorded flight log or flight assist. Map/camera actions cannot command the aircraft.

J explicitly selects the first connected gamepad or returns to keyboard. Left stick controls roll/pitch, right-stick X yaw, triggers increase/decrease throttle, A holds both brakes, Start opens the menu. Dead zone is 0.12 with signed rescaling. Selected-device loss pauses before another physics step; window focus loss also pauses. Automated mapping tests are synthetic and do not establish real-device calibration. Menu input cannot command the aircraft. Camera, panel and sound choices do not change native state.

Ground contacts and wheel forces come from native state. TAS subtracts copied NED wind/turbulence from earth-relative velocity; it is not IAS or a modeled airspeed sensor. Altitude is WGS ellipsoid height, not MSL/barometric altitude; VSI is kinematic and heading true. Body yaw rate is explicitly labeled rather than pretending to be a turn/slip instrument. No C172 limit arcs, RPM or unsupported sensor behavior are invented. Sound is original synthesized presentation driven by throttle/speed, not measured engine acoustics.

The fixed 120 Hz player retains bounded wall-clock debt; a stall pauses visibly and requires an explicit fresh restart. Unknown coverage/native faults stop the loop visibly. Human mode has no scripted feedback assists. The smoke driver is labeled separately and does not establish human handling realism. LGPL source/build instructions, replaceable JSBSim DLL, component notices, original authored source and exact package receipts are retained. This package does not install a global runtime or publish a release.
