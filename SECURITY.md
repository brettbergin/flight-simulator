# Security reports

Use GitHub's private vulnerability reporting for security findings when it is enabled. Otherwise contact the repository owner through their GitHub profile to arrange a private channel; do not post exploit details or user data in a public issue.

The current repository contains documentation tooling. Future runtime security requirements cover untrusted aircraft/world packs, archive extraction, native plugin loading, replay/save parsers, updates, and log redaction. Track those in [delivery policy](docs/delivery.md) and the backlog.

Supported runtime releases and patch timelines will be stated when the first simulator build is distributed. No playable release is currently supported.
