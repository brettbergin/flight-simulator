# Bounded original interactive native session

Engineering implementation of [ADR 006](../../../docs/decisions/006-interactive-prototype.md), using the exact [combined model inventory](../models/original-interactive/inventory.json). This preserves the separate historical flight/cart proof APIs and creates no new wire records.

Include `<flight/interactive/session.hpp>`, link `flight::interactive`, namespace `flight::interactive`. Construct a default `SurfaceConfig` and `AnalyticSurface(config, prepared_identity(config))`; only that exact default prepared world is admitted. Supply its immutable shared pointer, model root and fresh session ID in `Config`. Default ground starts at requested CG ellipsoid height 1.05 m with running-idle engine and full brakes. For the named airborne start set `start=Start::airborne`, height 1000 m, forward `55*cos(.02)` m/s, down `55*sin(.02)` m/s, pitch `.02` rad and `trim=true`. Other recipes reject.

All calls and destruction remain on the constructing thread. `latest`, `atmosphere`, `held`, `events` and fault text return copied values. Register native sources through the trusted host only; human consumers use fixed `pilot.controls`/pilot authority. Submit accepted v1 axes commands for the actual next tick. `step_fixed` performs one authoritative step and returns `completed`, `paused`, `coverage_blocked` or `discarded`, plus applied commands. `apply` handles accepted v1 pause/scale lifecycle at the current completed boundary. Close on the owner thread before reset/join; a discarded executive cannot resume.

Runtime `Config.hz=120` and `purpose=ClockPurpose::runtime` are fixed. Research 60/240 Hz requires explicit `purpose=ClockPurpose::convergence`, and is not a runtime option or a coupled-model convergence claim. The caller owns monotonic wall pacing, at most 32 steps per presentation batch and explicit pause at stalls over 250 ms. Time scale never changes solver dt. Rendering never integrates physics or adds gear contacts.

The module rejects changed inventory/XML before parsing and nondefault surface/source identities before allocating an executive. Current CG and all gear samples precede control/friction mutation. Known pure misses preserve clock/held/pending/publication; unexpected callback/identity failures discard the executive and preserve the previous completed publication. Resident footprint and actual post-step guards follow ADR 006; they are not an analytically proved continuous-motion bound or aircraft envelope.

`snapshot_json` retains all solved contact arms/forces/WOW; `command_json` retains brakes and the explicit command authority in existing strict v1 records. Full mixture, fixed gear and zero flaps are the only supported configuration. No cold start, piston/propeller/Cessna calibration, save/resume or formal training credit is established.

The compiled `source_fingerprint()` hashes the six declared public adapter/driver paths and LF-normalized bytes in CMake order. It is a public-source fingerprint distinct from the private precursor. [Headless tests](../../../tests/interactive/README.md) reproduce the actual single-executive flight and bind their final source/model/schema evidence independently.
