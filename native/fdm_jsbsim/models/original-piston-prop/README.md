# Original piston and fixed-pitch prototype source

Identity: `original-piston-prop-v1`, version `0.1.0-prototype`, backend model `original-piston-prop`. Status: original engineering prototype, unvalidated; no backend trial or runtime acceptance is represented by this package. [ADR010](../../../../docs/decisions/010-original-piston-profile.md) admits only `piston-cold-ground` after the source/reference and consumer gates land. This is not a C172S model, manufacturer procedure, electrical simulation or training device.

The [inventory](inventory.json) binds three original XML files, the [parameter ledger](parameter-ledger.json) and [full MIT notice](NOTICE-MIT.txt). Project-original airframe, inertial tensor, tricycle gear, controls and polynomial aerodynamics are attributed to the unchanged original-interactive package. Engine, fixed-pitch propeller installation, four numerical tables and effective scalar choices are authored engineering inputs. No vendor aircraft/engine XML or restricted manufacturer data was copied. JSBSim syntax/API identifiers and inspected algorithms belong to the separately pinned library/component policy.

One four-cycle piston drives a two-blade fixed-pitch propeller, 6 ft in diameter, through a direct drive ratio of 1. Explicit parameters, units, table domains/interpolation, backend constants, defaults and limitations are listed in the ledger. XML backend format2.0 and propeller convention1.1 are not package versions. MaxHP/RPM values are scaling/geometry parameters, not measured limits or hard clamps. The positive CP curve is deliberately dissipative and does not provide realistic windmilling or freestream self-start behavior. No thermal/oil indications, hot/flooded starting, manufacturer magneto-drop limit or calibrated performance is claimed.

Only the future consumer may initialize a fresh cold engine with IC engine-running flags false, mixture 0, ignition off, starter false, fuel feed true and 100 kg usable fuel. No running/airborne preset, trim, hidden positive tick, RPM injection or `InitRunning` is admitted. Native simulation owns actual shaft/combustion/control/fuel state; presentation cannot infer it from throttle or switch artwork. Existing legacy source and behavior remain separate.

Independent equation/unit/discrete-step references must freeze before backend traces. XML syntax/hash/topology/ledger checks are source integrity evidence only; they do not establish startup, taxi, shutdown, deterministic/convergent physics, package correctness or a phase gate. Runtime and exported Windows proofs, source/license closure and pilot review are later evidence.
