## Arithmetic provenance

The 31 directions come from the general right-handed Rodrigues rotation theorem, applied first about the declared pitch axis, then about UP by negative yaw. They are not copied from the ADR component table or a producer Basis implementation. Left's pitch axis is -Z; right's is +Z. A positive pitch rotates either base toward +Y. Positive yaw sends left's Z negative and right's Z positive. Exact signed permutation matrices separately test aircraft-basis application and inverted aircraft-up, so a world-stabilized view cannot silently pass.

Every yaw/pitch input is an exactly representable dyadic radian value (0, +/-0.25, +/-0.5). Decimal Taylor series, with decreasing alternating terms for |angle|<=1, stop below1e-105 per next term. Two working precisions,110 and140 decimal digits, must yield identical serialized binary64 expectations. This is a reproducible high-precision reference, not a universal libm accuracy proof. Cockpit/panel ideal normalized vectors supplement a required **same-engine exact regression of the existing expression/order**; ideal references must not replace that regression or permit reordered legacy computation.

Five scalar filter references use the analytic fixed-target solution of `d(offset)/dt=9*(desired-offset)`. The three-frame sequence uses `desired+(previous-desired)*exp(-9*dt)`, independently of the producer's Vector3.lerp expression. Dyadic durations cover zero,1/64,1/8,1/4 and1/2 seconds, including the existing0.25 clamp. Presented ownship positions differ deliberately from a separate raw endpoint: both responses add their offset to the **presented** translation. Immediate uses desired; smooth carries its own prior offset. A repeated zero-time/same-pose draw cannot advance the filter. First-draw, paused, interior, mode-response reseed, floor and coherent common-origin branches are separate declarative cases, not inferred from a moving trace.

`binary64_le` is a private fixture descriptor. Decode its eight little-endian bytes to a real FLOAT in the future test driver; do not route expected values through Godot's decimal JSON numeric conversion. Human display strings are nonnormative. JSON integer fields are test metadata, not production Variant admission. Explicit edit descriptors must construct actual INT, BOOL, StringName, Object and nonfinite FLOAT cases rather than approximating them with strings. The two adjacent FOV cases are the actual binary64 neighbors immediately below35 and above90. Case IDs are stable within this packet.
