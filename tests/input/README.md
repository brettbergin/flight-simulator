# Input boundary checks

`input_checks.gd` is a synchronous RefCounted harness with static `run()->Dictionary`. Stage this directory at `res://input_tests`, the actual mapper/codec at `res://input`, and call it with the pinned Godot editor headlessly. It tests real helpers, complete existing kind:axes payloads and exact six-key sample results; all controller readings are synthetic copied dictionaries. It does not load a native worker or use physical hardware.

`scene_checks.gd` is a separate RefCounted integration harness with asynchronous `run(host:Node)->Dictionary`. Its host supplies `check(bool,label)`, adds the production scene to a settled tree, and awaits this function. The synthetic scene overrides only raw-device collection; ordinary production mapping, Apply, focus, removal, generation, native pause/advance and fresh-session handlers remain active. It uses the existing staged native bridge/models and joins the worker and sound before returning. Run it serially, outside an exclusive performance capture. No OS joypad polling or key injection occurs.

`reference.json` preserves the 38 pre-consumer private analytic cases byte for byte (SHA256 bb1e528c28ac2a536e15c071b260d911912caf31818656b61d3c09d8f21c85cd). Its PRIVATE_PRE_CONSUMER classification identifies its authorship chronology, not a pilot profile. `generate_reference.py` is portable and uses repository-relative ADR008, Python Fraction, and selected exact decimals without importing a consumer. The private original remains immutable. Its analytic numbers predate mapper comparisons. The absolute 1e-12 allowance was selected before the first actual arithmetic comparison; it is not a physics or hardware tolerance.

Cases cover asymmetric calibration, reversal/deadzone/saturation, separate pedals, bounded slew, key aliases/opposites/start bias, explicit timed30/60/144Hz schedules, brake-hold initialization/preservation/edges, suspended diagnostics, takeover/idle, sparse missing controls and generation changes. Further active negatives test caller/return copies, invalid elapsed/NaN/duplicate readings, unobserved buttons, consecutive wheel pulses and persistent key plus wheel aliases. Runtime bounds use actual JOY_AXIS_MAX/JOY_BUTTON_MAX, not gamepad-layout guesses.

Codec tests mutate otherwise complete valid documents to exercise duplicate and escaped duplicate-key detection, in addition to bounds, invalid UTF-8, truncation, nesting and incompatible preset fields. File tests use only unique disposable explicit absolute paths. Windows tests reread successful replacement bytes, then require a real external share-lock failure to preserve the old bytes and verified temporary file, and a directory target failure to preserve its marker. The hidden helper owns its own bounded process, releases its FileStream and joins before return. Other operating systems assert an explicit unsupported result with the original and temporary preserved.

Successful replacement tests alone do not prove atomicity. The actual Windows replacement implementation requires independent source review; the earlier Godot delete-then-rename candidate was rejected. These fixtures do not claim interrupted power-loss durability, unsupported-filesystem atomicity, independent mixture capability, physical gamepad/yoke/pedal qualification, pilot handling, or phase acceptance. Retained files/results are controlled synthetic test evidence, not default settings, pilot profiles, or automatic preset persistence.
