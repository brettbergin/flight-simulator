Their original proposal/unratified status records their preparation time. `ratification-v1.json` separately binds accepted ADR013 and the coordinator's decision before consumers; it does not rewrite historical provenance or imply native validation. Original material is MIT.

`wind_checks.gd` exposes static `run() -> Dictionary`. Stage it as `res://wind_tests/`, the cue as `res://world/wind/`, accepted simulation helpers as `res://simulation/`, NativeReadings as `res://cockpit/instruments/`, and the unchanged existing instrument reference as `res://instrument_tests/reference.json`. This driver creates no native executive, device, facade instance, scene or clock. Its manually labeled synthetic Readback uses the shared facade source pin only as a structural fixture; actual binary/source closure is a separate acceptance obligation. WindCue reads that single integrator-owned constant without calling the facade.

The suite also rejects malformed/wrong-source/turbulent/wet input, checks retained and empty states, copies, an actual vertical residual preserved without clamping, min-subnormal wind and full uint64 identity. Run `python reference/generate.py --check` for independent read-only byte regeneration.
