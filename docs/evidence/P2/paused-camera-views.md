## Pilot-visible behavior

Pause and choose **Views** for Cockpit, Forward horizon, Left window, Right window, Panel, Chase or Orbit. The page edits a copied draft; Apply adopts it, Cancel discards it and Defaults only changes the draft. FOV is bounded to 35–90 degrees. External response selects smooth or immediate camera offsets; it does not filter aircraft translation, change simulation state or create a flight assist. Choices remain local to the current session. Successful fresh flight adoption restores Cockpit, FOV72 and smooth response.

Cockpit/Panel preserve their existing expressions and pilot eye. Side-window pitch rotates about the view's right axis before signed yaw. Chase and Orbit follow the same presented aircraft pose used to draw the aircraft; smooth response uses the frozen exponential offset rule. Existing free look, recenter, focus/release handling and deliberate traditional-mode transitions remain in force. This leaf changes no native physics, aircraft geometry, Mapper, Facade, held-control vocabulary, save/review format or aid layout.
