# KAWO runtime v1 compatibility amendments

This companion and [ADR029](../../decisions/029-kawo-runtime-admission.md) extend the named historical contracts only after checked runtime-contract acceptance. The original documents remain byte-for-byte unchanged: older reference generators and the local-player source allocation retain their exact inputs. No historical hash, fixture, storage record or numerical expectation is replaced.

The [complete runtime contract](kawo-runtime-v1.md) owns the new branch. These scoped amendments define compatibility; they do not implement a feature, accept an aircraft, or qualify geographic flight.

Requested-source/provider checks precede executive allocation; unavoidable default-ground vendor bootstrap is non-authoritative, and the certified callback is installed before canonical ASL-first IC/RunIC. Actual final pose/gear/clock/state verification precedes publication. No arbitrary pose/provider injection, geographic fallback, hidden settling, Cessna or phase claim follows.
