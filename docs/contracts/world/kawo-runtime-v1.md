## Conservative grid readiness, including altitude-to-terrain offset

The original analytic branch retains its existing actual-query/post-step footprint policy and arithmetic. The geographic branch uses the following deliberately conservative engineered domain, independently tested before acceptance; this is not a continuous-collision theorem or unlimited-altitude flight guarantee.

During initialization, C is the exact pinned requested CG converted to ECEF and projected into the grid anchor EUS frame, with the same checked canonical conversion/rounding policy. Construct and certify its40m readiness rectangle, immutable provider/source and3D4m query domain/cone/support-containment/Boundary context **before executive allocation**. This validates the requested future geographic state, not a default temporary vendor pose. The retained public vendor API cannot install a caller callback until FGFDMExec/FGInertial exist. Its constructor and LoadModel make unavoidable default-ground queries during non-authoritative bootstrap: constructor Allocate/InitializeModels/Propagate InitModel sets a temporary AGL-based location and LoadInputs stores AGL-derived inputs. These are real vendor computations with temporary state effects, not prepared-grid queries, no-ops or observed project callbacks. Their actual count is unobserved unless separately instrumented, and source review alone does not prove every effect erased.

This contract admits that bounded bootstrap stage without a vendor edit, new constructor/injection API or fallback geographic provider. No bootstrap ground value may admit a canonical pose/world/publication or advancing tick. After exact pinned model load, install the certified immutable geographic callback before canonical ASL-first IC staging/RunIC as above. **Every subsequent project/custom provider callback capable of contributing to initial/live candidate state**, including setters, RunIC and zero-time startup/diagnostic getters, uses the initial requested-CG40m certificate, strict3D4m/cone/support/domain and existing Boundary guards before sample use. No uninitialized/default publication or bypass of an installed guard is permitted. The existing terminal Unbind disposal-getter exception remains only after authority ends: it cannot call a provider, Run, satisfy a pose/coverage check or publish state. A missing/uncertifiable/unexpected active query refuses and disposes the candidate. Switch C to the actual completed publication only after all tick0 canonical pose, actual gear/velocity/fuel/clock/controls/atmosphere/callback verification succeeds, before any session publication/adoption. Thereafter C is the previous completed native CG projected into the grid anchor EUS frame, and every step establishes a fresh certificate from that publication. The separate offline physical probe's8m rectangle is narrower evidence, never acceptance or replacement of this runtime40m/4m policy.

For either initial or completed C require finite C, `-1024 <= C.y <= 8192` meters. Every actual geographic callback query q must project within a closed **3D** 4m radius of C (including vertical displacement), and meet the core's actual geodetic-ray cone. Initial/pre-step CG and rotated gear queries meet the same domain. Keep speed<=150m/s, body-rate<=3rad/s and existing finite/gear-radius2.5m guards. Reject a query outside the admitted domain; during mutation that means discard, not a late preflight success. The 4m domain exceeds the existing120Hz3.8625m engineered footprint but does not assume every possible solver trajectory stays inside it; actual callback guards remain mandatory.

For the ideal continuous geodetic ray Q(h)=A+hD passing through q at hq, displacement to a terrain-bracket Y endpoint Yt is `(Yt-q.y)*D.xz/D.y`. This motivates the full altitude-to-terrain padding; it is not the bracket's4.096021m per-axis span. Core cone guarantees `abs(D.x),abs(D.z)<=0x1.0624dd2f1a9fcp-9` and `D.y>=0x1.ffff583a53b8ep-1`; each component ratio is strictly less than exact dyadic1/256. Core absolute vertex bounds imply `Ylo>=-1000-1/64` and `Yhi<=4096+1/64`. With q.y in[C.y-4,C.y+4], the nominal maximum endpoint gap is <=9196+1/64m and the nominal support displacement is `<4+(9196+1/64)/256 <40m`. Actual independently rounded B64 projection of q need not equal Q(hq) exactly. Therefore this estimate never alone admits a callback: the exact actual A,D support-containment predicate below is mandatory. It certifies the actual support inside the ready rectangle rather than silently assuming a zero conversion discrepancy.

Before applying a tick's controls or Run, certify the entire outward-rounded rectangle `[C.x-40,C.x+40] x [C.z-40,C.z+40]` with grid.coverage. It must be ready, inside the same half-open grid bounds and within the4096-cell core coverage cap. At this fixed4m spacing an outward-rounded80m-wide interval touches at most22 cells per axis (including endpoint ownership), at most484 cells. No epsilon fills an outer-boundary/missing-cell failure. This larger readiness region is intentionally conservative and may pause before the actual aircraft reaches missing terrain.

The certificate's numerical operands and predicates are fixed as follows. Form anchor ECEF and east/up/south using the accepted core binary64 geodesy, identical component/trig grouping and no FMA/contraction. Canonical projection first separately subtracts anchor ECEF components, then evaluates each basis dot as t0=a0*b0, t1=a1*b1, s01=t0+t1, t2=a2*b2, result=s01+t2, materializing every binary64 primitive. Altitude comparisons use the same exact represented operands and inclusive stated bounds. Unsupported floating environment/query conversion or exact-kernel capacity failure refuses certification without changing caller FENV; preserve the accepted core's preparation semantics.

For each rectangle bound, first form the **mathematical dyadic** value C.axis+/-40; then compute its least outward binary64 enclosure. Runtime helpers may share private operand construction/predicates with the component only through source-bound internal headers/implementation; no Definition, public ABI or fixed tolerance changes. Verify actual speed/rates/finite state and all existing time/publication guards. Unexpected post-step failure discards the executive and leaves prior publication historical. A paused or coverage_blocked host accrues no solver ticks; fresh explicit reset is required if safe continuation cannot be admitted.

Independent readiness fixtures must include CG.y8192/terrainYlo-1000-1/64 and CG.y-1024/terrainYhi4096+1/64, nonzero D.x/z at the actual cone operands, a query near the3D4m boundary, exact/near outer and internal grid edges, missing cells outside the old3.8625m disk but inside the full ray support, complete vs partial support,4096 cap, incorrect span-only padding, invalid conversion/support containment and post-Run escape.
