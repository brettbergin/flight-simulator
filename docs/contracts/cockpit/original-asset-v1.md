## Units, geometry and closed asset roster

One local unit is one meter. Local +X is right, +Y up, +Z aft, using the existing `OriginalReadonlyCockpit` origin. It is not a new CG, structural datum, eye-to-CG calibration or terrain plane. Blender authoring maps reference `(x,y,z)` to `(x,-z,y)`; the existing Y-up glTF export maps Blender `(x,y,z)` to `(x,z,-y)`. The net reference-to-GLB transform is identity. No scale correction, axis-flip parent or offset is permitted at import.

The normative design reference transcribes all 74 non-panel/non-bezel parts from `flight_cockpit.gd`: dimensions, centers/endpoints, explicitly assigned primitive subdivisions, seat-back rotation, materials and dynamic parents. It is original contract data, not a loader schema, candidate mesh or renderer observation. Primitive properties not assigned by that source retain the pinned engine's actual defaults, including cap/subdivision behavior; the independent pre-output baseline must freeze those values and arrays rather than substitute Blender primitive defaults. The 54 static parts are below identity `Static`; the 20 control parts are below their named pivot. Geometry may gain UVs/material assignments only. Keep the same primitive surfaces, open windows, knee space, rod endpoints, panel backing order and silhouette. No added glazing, caps over openings, seams made from new geometry, colliders, cockpit shell, obstruction or LOD substitution.

GLB root is `OriginalCockpitAsset`, identity translation/rotation/scale. Its exact direct children are identity `Static` and these eight nodes. Markers are empty Node3D nodes. Pivots are Node3D nodes whose geometry is in the reference's named children.

## Original materials, UVs and resource bounds

Seven exact imported materials are `WarmTrim`, `Cloth`, `Dark`, `Metal`, `Leather`, `Accent`, `Black`. Their source Godot color tuples, roughness and metallic factors are frozen in the design reference. Preserve those base factors and verify the pipeline's existing linear-glTF versus Godot color conversion exactly once. Every material remains opaque; no alpha blend/cutout, emission, parallax, displacement or transparent windshield. No added light, postprocess, exposure or environment change.

Only Cloth/Leather/Dark/Black receive original UV detail: a shared 256x256 RGBA8 grayscale albedo tile and a shared 256x256 RGBA8 metallic-roughness tile. Albedo RGB is 236..255 with alpha255, a modest modulation of the source base color. Roughness texture G is 243..255; R/B/A are255, no occlusion input; existing metallic factors therefore remain intact. These are deliberate original material choices, not measured aircraft materials. No normal map in v1, so geometric normals and silhouette remain the accepted baseline. WarmTrim/Metal/Accent retain untextured source factors; runtime rings/display stay exact.

Declare original UVs for every textured primitive in editable source; seams and repeat orientation must be visible in the reference checker. UV coordinates/tangent data are finite and bounded to [0,1]; shared repeat tiles use one repeat per primitive's original normalized UV domain. Do not change mesh positions to hide UV seams or add a uniquely painted large atlas. Albedo is interpreted as sRGB; roughness is linear data. No borrowed artwork, manufacturer markings, photographs, sampled cockpit labels, embedded font or external texture reference.

Exactly two embedded PNG images, each 256x256, correspond byte-for-byte to the two original source PNGs. Each uses a full mip chain, repeat wrapping and linear mip filtering in the actual imported material. Exported GLB is at most 12 MiB, decoded mesh/accessor storage at most 8 MiB and at most 20,000 triangles; these are parser/resource guards, not FPS claims. Exact baseline topology correspondence still controls within those guards. Unknown extra resources fail rather than consume spare capacity.

RGBA8 full-mip texel accounting is 349,524 bytes per tile, 699,048 for both. Add the unchanged 8,388,608-byte calculated panel color plane separately: 9,087,656 bytes of calculated color texels, excluding driver/target attachments and any transient copies. Actual imported dimensions, format, compression/mipmap/filter/wrap flags, image/material sharing and exposed rendering counters must be observed. Do not equate compressed PNG/GLB size or this calculation with total VRAM. No per-frame texture upload, dynamic tile regeneration, additional panel target or material copy per part is permitted.

Editable `.blend`, generation source, exact tool/export settings and source PNGs belong in authoring inventory. Use the existing pinned Blender4.5.14 LTS/build62c1db4208e8 and Godot4.7.2 route only after actual executable/archive/source pins are admitted. No downloads or tool execution are authorized by this proposal. The `.blend` must open without external dependencies and have meter scale1, applied mesh scale, declared named pivots and no unused executable text/add-ons; generation begins from a cleared factory scene and changes no user preferences. Rebuild guarantees checked semantics, not byte-identical future Blender serialization.
