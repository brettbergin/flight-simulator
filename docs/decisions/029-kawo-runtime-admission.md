# ADR029: Closed KAWO world, ground start and runtime admission

Status: proposed contract under [#243](https://github.com/brettbergin/flight-simulator/issues/243), normative only after its checked contract merge. This is a bounded extension of [ADR028](028-kawo-source-and-resident-environment.md), not geographic gameplay or phase acceptance. The owner prioritized airports and environments after the Players flight-menu checks. Existing aircraft, source, hardware/pilot and parent P3/P4 gates remain open.

## Decision

Adopt the complete [KAWO runtime v1 contract](../contracts/world/kawo-runtime-v1.md) before its consumers. Add one explicit closed world selector `kawo-prototype-v1`, with `original-synthetic` retaining every current default. First geographic scope is the original direct-thrust engineering model, ground-ready, calm, seed42/runtime120Hz and one separately frozen runway34 engineering pose. The existing generic start name is qualified by an exact world/model/source tuple. It is not renamed in old archives or native storage. Geographic airborne/apron/piston/noncalm combinations reject.

The fixed seven-file pack binds the accepted canonical ground payload, closed compiler receipt/runway geometry, reviewed airport/dossier, source notices and fixed start recipe through an external first-party catalog. Native contact, renderer, start authoring and basic runway locator consume the same canonical surface and compiled physical endpoints/footprints. There is no runtime FAA/PROJ conversion, height flattening, second physics authority or in-flight world replacement. Synthetic Taxi/landmark/circuit guidance remains explicitly unavailable in KAWO; its physical runway locator is retained. Datum uncertainty, original-aircraft limitations, source dates and incomplete obstacle/operational coverage stay visible.

There is no hash-of-unwritten-code prerequisite or extra contract-only round trip for ordinary population of already fixed fields. Changing an interface, representation, numerical rule or source choice still requires review before its consumers. Missing facts never authorize placeholders, loose hashes, alternative transforms, fabricated pose expectations or interim permissive admission.

## Native initialization and delivery authority

Validate immutable source/provider and the requested-CG40m readiness certificate before executive allocation. Retained JSBSim APIs unavoidably perform real default-ground computations during constructor/LoadModel bootstrap before the caller can install its callback. Those temporary effects are explicitly non-authoritative: they admit no geographic world/publication or advancing tick, their count is unobserved unless instrumented, and source review does not prove every effect erased. After load, install the certified grid callback before ASL-first canonical IC staging/RunIC. Every active project callback uses the unchanged strict3D4m/cone/support/Boundary predicates. One RunIC may internally use suspended-integration Run; no caller advancing Run/trim/settling is allowed. Full actual tick0 pose, loaded gears, velocity/rates, fuel/engine, controls, atmosphere and clock checks precede adoption. The separate offline physical probe supplies no runtime-constructor/readiness acceptance.

Preserve existing native Readback/reply keys, ordered25source/18control membership, backend variant labels and current generated-identity schema. The added source-bound resident component and separately closed four-translation-unit/strict-FP/link companion bind the actual geographic implementation. Manifest raw pins live outside both hashed input closures; no digest cycle or copied success field qualifies a package. Fresh native expected identity, actual loaded source/module locality, reconstruction, replacement and Windows delivery remain mandatory.

## Compatibility and evidence

The optional fifth bridge/facade world selector preserves old calls and reset's bound world. Frontend complete preflight precedes history resolution and actual old close/join; a later native race/initialization failure leaves no adopted flight rather than reviving history. Terrain chunks retain exact original f32 vertices/P00-P11 facets under one common origin translation, with the contract's separate measured presentation budgets. No GPU/pixel bit identity or geographic survey accuracy is inferred.

Recording3/archive3 is reserved for the exact geographic original-model tuple, preserving old1/2 bytes and semantics. Historical source qualification remains distinct from current native authority. PracticeSource/ExternalRecordedReview/SQL/B44/storage ABI stay unchanged; immediate practice begin, actual joined close, original-player ledger, uncertain mutation barriers and explicit successful Save association/Open source-and-tick comparisons remain required. A menu-only result does not satisfy the full history/export journey.

Acceptance requires independent expectations before outputs, old-world regressions, full-altitude readiness/actual callbacks, qualified tick0, manual taxi/takeoff/circuit/landing/braking, shared native/render geometry, history/file/lifecycle behavior and editor/portable/rebuilt-library/installed offline evidence with measured resources. Contract merge itself establishes none of those results and does not close #243, the runtime consumer, parent airport work, aircraft/pilot or phase gates.
