## Useful result and authority

Provide a real ready/cold apron start, identifiable cockpit-visible taxiway/holding/parking references and the same original diagram: actual apron -> either selected runway36/18 stop reference -> deliberate pilot runway entry/flight -> manually selected return link -> parking. Movement always uses existing pilot controls. A runway start followed by taxi to the apron is only familiarization, not completion of this intended journey. No automatic arrival/parking, steering, clearance, ATC, evaluator, scoring, saved physics resume or collision authority is added.

World, all pavement extents/material/contact physics and existing three starts stay intact. Current shader's four continuous bars are corrected to two solid/two dashed; this is a narrow depiction correction, not a claim the old bars were correct. Original signs are factual-convention-informed synthetic geometry, not a surveyed airport or certified installation. Runway numbers identify existing synthetic pavement ends, not surveyed thresholds/magnetic data. Ordinary simulation remains sole authority.
