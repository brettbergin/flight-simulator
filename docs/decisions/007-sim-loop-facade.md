# ADR 007: Synchronous simulation facade and render-origin adoption

Status: proposed contract; normative after its contract PR merges. It authorizes no consumer, closes no phase gate, and does not accept [#20 SIM-LOOP](https://github.com/brettbergin/flight-simulator/issues/20). Owner/P1 renderer and human qualification remain separate. Contract issue [#112](https://github.com/brettbergin/flight-simulator/issues/112). Supports PRD-002, PRD-007 and SAFE-030. Basis: accepted [v1 contracts](../contracts.md), [ADR 006](006-interactive-prototype.md), [ADR 003](003-geodesy-and-render-origin.md), and accepted #110 / PR111 motion work at main `af705ee` (frozen source `37467e8`).

[ADR016](016-generated-native-build-identity.md) defines the subsequent per-build expected native identity resource and exact staging evidence. It retains this facade's actual metadata mismatch rejection and copied Readback contract; its consumer changes wait for the protected contract merge.

## Decision and ownership

Introduce `app/simulation/session_facade.gd` and `render_origin.gd` over the existing synchronous `FlightInteractiveSession`. One facade on the Godot main thread owns one joined worker and one native executive; construction, calls, close and destruction of the native Session stay on that worker. There is no autonomous runner, new mailbox protocol, shared native resource, new wire record or second solver. Every facade call, origin transaction and returned Godot value belongs to the main thread; readback/intent/result dictionaries and arrays are deep owned copies.

The first adoption uses only ADR 006's exact model, prepared world `04bff5a0bcf3509990f6276b2548a28268f57fc96d218a7ca51cab1990ec1ff5`, seed 42, runtime 120 Hz and two named starts. Validate native open metadata, matching aircraft/weather session/tick/position, held axes and pinned identities before becoming live. Native model/source and provider guards remain authoritative. General terrain streaming, source replacement, new aircraft, saved-state resume, sensor behavior and geographic/geoid expansion require their own contracts/evidence; this facade does not supply them.

## Callable surface

All mutators return an owned Result containing `ok`, explicit `error`, actual `completed` count, copied Readback and ordered actual `applied_commands`/`events` arrays. Nonstep operations complete zero ticks. These are app values containing unchanged v1 records, not new persistent/wire schemas. Argument rejection changes no accepted sequence, controls or native clock; the explicit overload/overflow cases below may change host mode. Native acknowledgements are distinguished from local intent acceptance.

| Method | Required behavior |
|---|---|
| `start(model_root:String, named_start:String)` | Closed prerequisite; `ground-ready` or `airborne-prepared` only, with unchanged ADR 006 recipes. Create fresh session, publish actual tick 0, copy held controls, initialize scale 1/debt 0/sequences 0 and collapse visual history. Failed initialization stays closed with diagnostic/historical values. |
| `set_axes(axes:Dictionary)` | Validate/copy the complete accepted axes payload, mixture 1 and explicit normalized ranges. Accept only live/unpaused. Coalesce latest continuous pilot intent locally; this is not native queue acceptance. No caller tick/source/authority, system/property write or hidden feedback. |
| `advance_wall_us(elapsed_us:int)` | Explicit monotonic microseconds since caller's previous settled boundary. Accrue/debit exact pacing below; stamp pending changed intent before the first due step. Drain at most 32 actual ticks per call, return actual outcomes and ordered records. Zero due ticks preserves publications/history and performs no solver step. |
| `set_paused(value:bool)` | Accepted SessionControl at current completed boundary; pause snaps presentation to actual native endpoint and excludes paused wall time. Held controls, accepted pending commands and exact fractional debt remain. Resume ordinary pause only; stalled/blocked/discarded requires reset. |
| `set_time_scale(value:float)` | Only 0.25/0.5/1/2/4. Caller settles preceding wall interval under the old scale first. Acceptance changes future accrual multiplier only; native dt and existing debt remain. Allowed during ordinary pause, not terminal/stalled states. |
| `reset(named_start:String)` / `close()` | Pause/drain observable lifecycle history if possible, close and require joined confirmation before new allocation. Reset reuses verified model root, fresh session ID and declared recipe; resets intent/cache/sequences/debt/origin presentation. Close is idempotent and retains only labeled historical copies. |
| `readback()` | Deep copy of latest verified aircraft/weather/held controls, session/model/world identity, native outcome/live/paused/scale and host mode/error/debt. Does not query/advance or redeliver records. Canonical geometry is derived from copied native truth. |
| `visual_pose()` | Separate owned presentation value with validity, endpoint tick strings, alpha, origin version and local Transform3D. Cannot be submitted to physics or serialized as AircraftSnapshot. Empty/fault has explicit invalidity rather than an identity transform presented as live. |

### Exact owned app values

Every key below is present; no extra keys, omitted keys or sentinel empty dictionaries. `null` is Godot nil. `float` means finite binary64 scalar unless stated otherwise. Arrays/dictionaries are recursively copied on input/output; Godot objects and mutable native resources never cross this seam. Unchanged v1 record dictionaries retain their existing exact schema. The names below are in-process values, not additional wire contracts.

| Value | Exact keys and types |
|---|---|
| Result | `ok:bool`, `error:String` (empty on success), `completed:int` (0..32 verified actual ticks), `readback:Readback`, `admission:String` (`none`, `intent_stored`, `queued`, `lifecycle_accepted`, `rejected`), `native_rejection:int|null`, `applied_commands:Array[ControlCommand/v1]`, `events:Array[OperationalEvent/v1]`, `observation_complete:bool`. Native rejection is the actual existing enum integer, present only after submit/session_control; never guessed from text. Local intent acceptance uses `intent_stored`, not `queued`. |
| Readback | `host_mode:String`, `error:String`, `historical:bool`, `session_id:String|null`, `tick:String|null`, `aircraft:AircraftSnapshot/v1|null`, `atmosphere:AtmosphereSample/v1|null`, `held_axes:Axes|null`, `native_outcome:String|null`, `native_live:bool`, `paused:bool`, `time_scale:float`, `debt_quanta:int` (nonnegative representable signed 64-bit), `native_fault:String`, `named_start:String|null`, `model_identity:Dictionary|null`, `native_source_fingerprint:String|null`, `prepared_world_sha256:String|null`, `world_anchor:Dictionary|null`, `canonical:Canonical|null`. |
| Canonical | `ecef_position_m:Array[float]` (3, X/Y/Z), `anchor_eus_position_m:Array[float]` (3, east/up/south), `body_to_anchor_eus:Array[float]` (9, row-major rigid rotation). Derived from the same raw native publication using binary64 scalar calculations, not interpolated Vector3 values. |
| VisualPose | `valid:bool`, `error:String`, `session_id:String|null`, `previous_tick:String|null`, `current_tick:String|null`, `alpha:float` (0..1), `origin_version:String|null`, `transform:Transform3D|null`. Invalid has `transform:null`; no live identity-transform substitute. Collapsed valid history has equal tick strings and alpha 1. |

`Axes` is the complete v1 axes payload (`kind:"axes"`, `roll`, `pitch`, `yaw`, `throttle`, `mixture`, `left_brake`, `right_brake`, `trim`), all eight numeric fields normalized per that contract. `model_identity` has exactly `id`, `version`, `backend_model` Strings from the verified ADR 006 package (`original-interactive-prototype`, `0.1.0-prototype`, `original-interactive`). `world_anchor` has exactly the existing finite `latitude_rad`, `longitude_rad`, `ellipsoid_height_m` floats from verified open metadata.

Host modes are `closed`, `live`, `paused`, `stalled`, `coverage_blocked`, `discarded`. `native_outcome` separately preserves the latest verified bridge outcome (`completed`, `paused`, `coverage_blocked`, `discarded`); it is not inferred from host mode. Native live/paused are the last verified native flags while open; after confirmed close `native_live=false` and `paused=false`. Terminal host modes/close label retained truth historical; ordinary pause remains current truth at its fixed native tick. Never-started closed Readback has all nullable fields null, `historical=true`, empty errors/fault, `native_live=false`, `paused=false`, scale 1/debt 0. Confirmed close may retain labeled historical publication/metadata, but resets debt 0 and invalidates VisualPose. A first failed start retains no claimed publication. Invalid VisualPose has null session/ticks/version/transform, alpha 0 and an explicit error.

Applied commands/events appear only once in the mutator Result that observes them; Readback contains neither array and cannot redeliver history. `observation_complete=false` signals known unverified/lost observation, including a terminal failure that prevents draining; it never invents missing records. True means no known loss/unverified observation, not that every accepted lifecycle event has already been delivered. A successful live resume/scale acknowledgement may have empty events and true while its real event remains pending until the next step_fixed reply; consumers must not infer that no event was generated. Native pending controls are bounded 4096; native lifecycle history is **4096 total accepted events per session**, not an undelivered queue. The bridge's delivery watermark does not free native capacity. While ordinary live/paused, suppress redundant pause/scale requests as successful no-ops (`admission:none`, no sequence/event allocation). A real lifecycle rejection/capacity exhaustion is visible and requires reset; no guessed acceptance or native API change. Results aggregate bounded native records without creating an unbounded facade history.

Wire ticks/sequences remain canonical decimal uint64 strings through the facade: validate, compare by length/lexical digits, checked increment and checked small difference. Never use signed 64-bit `int` or binary64 conversion for full-range wire identity/order. Helpers reject malformed strings and overflow at 18446744073709551615; next-tick/pilot/lifecycle exhaustion stops before submission. Exhaustion, actual admission rejection or inconsistent/throwing native replies enter host `discarded`, retain the last verified native outcome separately, invalidate presentation and close/join; reset is required. This host mode does not claim the native executive itself reported `discarded`. Presentation may use a checked difference no larger than 32, never an absolute tick converted to signed 64-bit. Native elapsed time remains the supplied derived value.

## Admission, lifecycle and partial completion

Facade alone emits `pilot.controls`, pilot authority, `unassisted` with no active assists, next actual tick and per-source sequence. A changed complete axes sample replaces held axes; unchanged intent sends nothing. Commit sequence and last-admitted cache only after native `ok/queued/rejection` confirmation. A rejection cannot silently step under unintended old controls: stop visibly before integration, retain verified publication and require explicit reset. Native ordering remains `(tick, authority rank, source_id, sequence)`; app UI cannot elevate its source or register another authority. [#21](https://github.com/brettbergin/flight-simulator/issues/21) owns device sampling/mapping/disconnect policy; sampling never changes aircraft state directly.

Lifecycle uses `session.owner`, current completed tick and an independent increasing sequence. Existing bridge `session_control` acknowledges acceptance but returns no OperationalEvents; `read_state` also does not deliver them. Events are delivered by a subsequent `step_fixed` reply, including a paused call returning zero completion. Do not synthesize an event from an acknowledgement. On pause and before ordinary close/reset, a paused `step_fixed(1)` may drain events without advancing physics; validate zero completion/unchanged publication. If terminal failure prevents verified draining, report incomplete observation rather than inventing or discarding history silently. No durable-history guarantee is introduced.

Validate every returned actual count, session/tick advance, matching weather, validity, held controls and unchanged identity before replacing owned truth. For n≥2, use n−1 then1 to acquire final adjacent snapshots; further split only at declared fixture input boundaries. A failed first segment prevents the second. Partial completion debits only verified completed ticks and retains actual commands/events in order. An inconsistent/throwing reply stops, keeps the last verified pair and closes/joins if possible; never guess completion. Known coverage miss is blocked before native mutation; unexpected callback/identity failure discards. Neither resumes/rolls back or substitutes zero terrain.

## Exact wall pacing and bounded overload

Use signed 64-bit checked debt arithmetic with 4,000,000 quanta per native tick; multipliers 1/2/4/8/16 correspond exactly to 0.25/0.5/1/2/4. Accrue `debt += elapsed_us ×120×multiplier`; whole due ticks are integer division; subtract only `actual_completed ×4,000,000`. Keep fractional debt across frames, pause and scale changes. Reset the caller's wall baseline on pause/resume/start so paused time is not later owed.

Before input admission or solver stepping, visibly pause if raw gap >250000µs or accrued debt >30 ticks. Preserve exact representable overshoot; no clamping, discarded debt or automatic catch-up. At 4×, the debt guard can trigger after 62.5 ms from zero: it is not described as a universal 250 ms stall. Normal accepted calls owe≤30 ticks, within the native 32-tick cap. Negative elapsed rejects before mutation. Check multiplication/addition before signed 64-bit overflow; overflow enters visible stalled error, retains previous representable debt and reports the rejected unrepresentable accrual rather than pretending it was added. Stalled state accrues/steps no further until fresh reset. These are host scheduling bounds, not aircraft limits or performance qualification.

## Canonical truth, presentation and origin transaction

Retain adjacent owned canonical ECEF binary64 scalar arrays and body-to-current-NED orientations. Convert orientations into the same prepared-anchor EUS frame before shortest-arc interpolation; never blend raw quaternions from different NED frames or Euler angles. Interpolate canonical ECEF in binary64, subtract the committed binary64 ECEF origin, rotate that binary64 delta with the fixed prepared-anchor ECEF-to-EUS matrix, and only then convert the three local EUS scalars to float Vector3. Alpha is fractional debt/4,000,000, bounded 0–1; live adjacent presentation is nominal 8.333 ms behind simulation. No extrapolation or native-state filter. Pause snaps actual native endpoint; fault clears history; fresh session/reset has no previous pair. A gap collapses to the newest valid endpoint. Physical contacts/force/WOW, instruments and maps consume raw native truth; optional visual geometry is separate.

The reviewed #110 map already uses raw native position. Adoption must preserve canonical prepared-anchor EUS for map/range/plane geometry independently of local render coordinates. Existing preview local-Vector3 history is a prototype reference, not sufficient canonical storage for runtime rebasing. Terrain/landmark/shader coordinates retain the prepared anchor; the exact stationary native plane/provider/hash never rebases.

`RenderOrigin` owns the fixed prepared-anchor EUS basis, binary64 ECEF origin and canonical uint64-string version. Construct a fresh registry for each native session, bound immutably to its verified session ID and prepared anchor; recreate all registration declarations/plans on reset, never reuse a prior registry or plan. Its exact app API is `register_participant(id:String, participant:Object, categories:Array[String])`, `unregister_participant(id:String)`, `rebase(origin_ecef:Array[float])`, `read_origin()`. Mutators return `{ok:bool,error:String,origin:OriginReadback}`. Registration is main-thread only, bounded 64 unique stable IDs, rejects missing participant methods/duplicate categories, and is prohibited during a transaction. Categories are `ownship`, `cockpit`, `camera`, `world`, `light`, `spatial_audio`, `local_particles`; explicitly absent categories are declared through registration with `participant:null`. No required category may be silently skipped. Absent-to-active replacement requires unregistering the absent declaration then registering the active root outside a transaction; any registration change invalidates presentation until a complete same-origin prepare/commit readopts all required categories. Each nonnull participant is a Node3D transform-owning root with the required methods; it covers its descendants; registered roots must not overlap in scene ancestry. Thus an ownship root may declare cockpit/audio/particle coverage without independently shifting those children. Every plan derives transforms from canonical data, not accumulated float deltas.

| Origin seam | Exact keys and behavior |
|---|---|
| Candidate | `session_id:String` (bound native session ID), `origin_ecef_m:Array[float]` (exactly 3 finite scalars), `ecef_to_eus:Array[float]` (exactly 9 row-major finite scalars, unchanged prepared-anchor rotation), `version:String` (checked next uint64). Deep owned per participant. Initial version is `"0"` at the prepared anchor; metadata is invalid until every required category is declared and an initial same-anchor prepare/commit completes at version `"1"`. A new session has a new registry even if version values repeat. |
| `prepare_origin(candidate)->Plan` | Returns exactly `ok:bool`, `error:String` (empty on success), `session_id:String`, `version:String` (both must match candidate), `data:Dictionary|null`. Successful data is owned opaque participant data; failure has data null. Participant validates its finite/alive transforms and all descendants it covers; registry validates common keys/session/version; stale plans from another session are rejected. No scene mutation during prepare. |
| `commit_origin(plan)->CommitResult` | Returns exactly `ok:bool`, `error:String`; true requires empty error. Uses only prepared owned data. These direct participant method calls are allowed; no awaits, signals, reentrant facade/registry callbacks, draw/presentation or native writes are allowed during prepare/commit. |
| OriginReadback | `valid:bool`, `error:String`, `committed:Candidate|null`, `active_ids:Array[String]`, `absent_categories:Array[String]`. Owned copies; IDs/categories are sorted. Before initial adoption committed is null and valid=false; failure to initialize supplies an explicit error. After commit failure `valid=false`; any retained committed value is historical metadata, not a claim that the scene remains coherent. |

Before a presented camera/ownship exceeds 2km from current origin, prepare all registered required active plans and reject invalid/missing/mixed-version results. Commit all plans on the main thread before the next presentation/draw; publish the new committed origin/version only after every commit succeeds. Failed prepare retains coherent old origin/scene, but suppresses further motion presentation beyond the 2 km bound and visibly pauses through the accepted lifecycle lane until adoption succeeds or the session resets. Unexpected commit failure is fail-stop: invalidate origin and VisualPose, suppress geometry presentation, stop wall accrual/solver calls, enter host discarded with historical native readback, report the failure and require reset/reconstruction of participants. After leaving the transaction, pause via accepted SessionControl if possible then close/join; no aircraft-state mutation or speculative integration is allowed. Do not return the old origin as if the partially changed scene were intact; no attempted rollback or further rebase over that scene.

Reproject both canonical endpoints into the new origin atomically, preserving alpha; stale local-frame history cannot blend across versions. Update camera clearance constraints from the canonical prepared plane in the new frame, never assume local y=0 after vertical rebase. Native world/provider/hash and prepared-anchor map geometry remain immutable. This extends ADR 003's translation-only origin policy; it does not implement later streamed-terrain/datum contracts.

## Consumer acceptance obligations

After contract merge and the applicable phase dispatch approval, implement only `app/simulation/` and focused `tests/integration/sim_loop/`, with coordinated controller/map/audio adoption. Preserve the runnable preview and old native APIs. Actual same-build tests use identical preadmitted tick/sequence command fixtures under 30/60/144 Hz, optional 240 Hz and jitter, all five scales and equal completed-tick lifecycle boundaries; compare common tick state/weather, actual applied commands/events, endpoint/debt and zero-step/partial/error outcomes. Live independently polled keyboard input is not exact-trace equivalence.

Test full uint64 boundaries, owned-copy mutation, invalid axes/admission, fractional debt/overflow/stall, paused-event drain, close/join/reset and malformed adapter replies. Independently evaluate adjacent interpolation, shortest wrap, same body/camera phase and raw map/instrument invariants. Origin tests preserve canonical arrays/native read_state/controls/command counts/world hash, reject missing/mixed-version participants and parent/child double-shift fixtures, and exercise repeated 2 km rebases with declared near-cockpit projection≤0.5px and relative spatial audio≤1mm cases. Exported checks must use active checks, not disabled assertions. Actual packaged/headless and short viewport evidence is required; no old prototype proof automatically closes #20, P1/P2, aircraft, terrain or human flight gates.
